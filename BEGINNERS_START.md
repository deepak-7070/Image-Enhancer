## 🆘 Troubleshooting

**App won't start?**
- Make sure you have Python installed
- Make sure you're in the correct folder

**Browser shows error?**
- Wait 5 seconds for Flask to fully start
- Try refreshing the page (F5)

**Can't see the app?**
- Check the terminal shows: `Running on http://127.0.0.1:8000`
- Manually go to: `http://127.0.0.1:8000`

**Port already in use?**
- Edit `html/app.py` last line
- Change `port=8000` to `port=8001` (or another number)
